# Reference material (read-only)

`kern/` is the original KERN design-studio template this repo started from.
It is kept only so its motion and layout patterns can be consulted.

- It is excluded from the pnpm workspace, builds, lint and typecheck.
- Nothing in `apps/` or `packages/` may import from it.
- It will be deleted once all eight sites are live (BUILD_SPEC.md, Phase 7).
