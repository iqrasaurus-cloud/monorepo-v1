# Letter audio

The 29 letter recordings come from **belajar-ngaji** by awahids: https://github.com/awahids/belajar-ngaji (folder `audio/hijaiyah`). They were copied on 2026-10-14 and renamed to this tool's letter ids.

Which file belongs to which letter follows that project's own letters page (`huruf.html`):
- `ha.mp3` is ح (Ha).
- `ha2.mp3` is ه (their file `Ha (besar).mp3`).

**Licence, to check before going live:** the repo's LICENSE is the MIT licence, but its copyright line names "Materialize" (the CSS framework the site uses). The repo doesn't say who recorded the voices or where the audio came from. Please confirm with the author, or replace these with your own recordings, before anything is published.

The source project's licence text is copied beside these files as `LICENSE-belajar-ngaji.txt`.

To replace one, drop a new file in with the same name. No code changes are needed.
